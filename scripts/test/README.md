# Test Suites & Auxiliary Scripts

Storage directory for standalone, branch, and auxiliary test scripts generated by the `test-coordinator` skill and its 12 sub-skills.

## Directory Structure:
- `load/`: Load & stress testing scripts (e.g., k6, vegeta).
- `resilience/`: Chaos injection, upstream partition, and recovery test scripts.
- `security/`: Hostile fuzzing, path traversal, auth DoS, and memory leak audit scripts.
- `stability/`: Soak test scripts monitoring RAM, CPU, and file descriptor leaks.
- `integration/`: Multi-service protocol, HTTP, and UDS smoke test scripts.

> **Note**: Standard unit and component tests remain directly inside Go source files (`*_test.go`) and Rust source crates (`tests.rs`, `tests/`).
